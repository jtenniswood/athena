# Athena

Athena is an unofficial web app and installable PWA for Hermes Agent. It
provides the browser interface; you need a separate, running Hermes Gateway.

- [Update the Hermes Desktop renderer version](Updating-Hermes-Desktop-Renderer)

internet. See the [project repository](https://github.com/jtenniswood/athena)
